# Migración: Separación de Sectores Asistenciales y Especies

---

## 1. Sectores Asistenciales Reales
- `UCI`: Cuidados Intensivos Hospitalarios.
- `INTERNACION_GENERAL`: Sala de internación médica.
- `AISLAMIENTO_INFECCIOSOS`: Box con presión negativa o bioseguridad.
- `RECUPERACION_QUIRURGICA`: Área posanestésica inmediata.

## 2. Especies (Atributo del Paciente)
- `Canino`, `Felino`, `Exótico`, `Otra / Desconocida`.
